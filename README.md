# Basit Hesap Makinesi

Toplama, çıkarma, çarpma ve bölme yapan küçük bir Python programı. Ek kurulum gerektirmez; Python 3 yeterli.

## Kullanım

```bash
python hesap_makinesi.py            # soru-cevap modu
python hesap_makinesi.py 12 x 4     # tek işlem -> 48
python hesap_makinesi.py 7,5 / 2    # ondalık virgülle -> 3,75
```

İşlemler: `+`  `-`  `x`  `/`  — sayı ile işaret arasına boşluk koy. Çıkmak için `q`.
